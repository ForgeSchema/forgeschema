# ForgeSchema

A planned PostgreSQL schema evolution engine in Go: inspect, plan, apply and verify.

Current status: planning complete; engine implementation has not started. This repository does not yet contain a usable binary.

Read [PLAN.md](PLAN.md) for the six-session prototype schedule and [RESUME.md](RESUME.md) for the exact continuation point. The project website is maintained separately in photozeitgeist/forgeschema.com; the owner will connect ForgeSchema.com later.
